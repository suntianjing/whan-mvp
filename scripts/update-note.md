# 每日更新作业（规划）

目标：用公开统计刷新行情数字，并保持站点仍是**纯静态发布**。

## 流程概览

```
住更局等公开统计 → 清洗/汇总 → 改写 data/market.json
                              →（可选）轮换精选 id
python3 scripts/generate-embed.py
静态托管 republish（整目录或 CDN 同步）
```

## 建议步骤

1. **拉取**  
   - 武汉市住房保障和房屋管理局（住更局）公开成交/备案统计页或开放数据。  
   - 仅使用允许转载/引用的公开数字；记下原始链接与抓取时间。

2. **映射到 `market.json`**  
   - `referencePrice.value` / `unit`：光谷东（或全市）挂牌/成交参考。  
   - `metrics[]`：挂牌均价、成交参考、新增挂牌等 3 枚芯片。  
   - `judgment`：基于本周变化的一句话判断（人工或半自动模板）。  
   - `updatedAt`、`updatedLabel`：写入实际更新时间（Asia/Shanghai）。  
   - `curatedNewIds` / `curatedSecondhandIds`：按周可轮换精选卡片。

3. **楼盘库**  
   - 新房/二手条目默认周更，不必每日全量改。  
   - 名称继续用示意楼盘或明确标注「示意」，避免误用商标品牌。

4. **内嵌同步**  
   ```bash
   python3 scripts/generate-embed.py
   ```  
   保证 `file://` / 离线路径与 `fetch` 路径一致。

5. **发布**  
   - 将 `/workspace/whan-mvp/` 同步到静态主机。  
   - 冒烟：首页参考价与时间戳、新房/二手列表、至少 1 个新房 + 1 个二手详情、说明页来源文案。

## 非目标（MVP 阶段不做）

- 服务端 API、登录、收藏云同步  
- 自动爬虫对抗与高频抓取  
- 真实备案核验（「查看备案」保持官网占位链接）

## 责任边界

站点数字若来自公开统计，须在说明页保留来源与「示例/演示」边界；正式对外前由业务确认免责声明与引用合规。
